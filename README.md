# Домашнее задание "Компоненты Kubernetes"

# Расчёт ресурсов Kubernetes-кластера

## 1. Расчёт ресурсов приложения
  Компонент       Количество копий            RAM      CPU
  База данных                    3          12 ГБ        3
  Кеш                            3          12 ГБ        3
  Фронтенд                       5         250 МБ        1
  Бекенд                        10        6000 МБ       10
  Итого                         21       30,25 ГБ       17

## 2. Рабочие ноды

Выберем 4 рабочие ноды по 8 CPU и 16 ГБ RAM.

При отказе одной ноды останется: 24 CPU, 48 ГБ RAM.

Этого достаточно для приложения.

## 3. Запас на служебные ресурсы

На каждой рабочей ноде оставим под системные процессы 1 CPU и 2 ГБ RAM.

После отказа одной ноды останется 3 ноды, на которых для приложения
будет доступно: 21 CPU, 42 ГБ RAM.

Этого достаточно, так как приложению требуется 17 CPU и 30,25 ГБ RAM.

## 4. Управляющие ноды

Для управления Kubernetes добавим 3 Control Plane-ноды по 2 CPU и 4 ГБ
RAM. Они будут отвечать за управление кластером и хранение его
состояния.

## 5. Итоговая конфигурация
  Тип ноды          Количество           CPU на ноду          RAM на ноду
  Worker Node                4                     8                16 ГБ
  Control Plane              3                     2                 4 ГБ
  Итого                      7                    38                76 ГБ 

Для деплоя приложения в разные окружения используем Helm Chart с
отдельными файлами конфигурации для Dev, Stage и Production.

Вывод: потребуется 7 нод: 4 рабочие и 3 управляющие. Такая
конфигурация позволяет выдержать отказ одной рабочей ноды, сохранив
достаточно ресурсов для работы приложения. Для базы данных и кеша также
необходимо настроить репликацию и размещение копий на разных нодах.
